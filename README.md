# Pomodoro Timer

A browser-based Pomodoro timer built with vanilla HTML, CSS, and JavaScript.

## Project Structure

```
pomodoro-timer/
├── index.html    # Markup and layout
├── styles.css    # Styling
├── script.js     # Timer logic
└── README.md
```

## How to Run

Open `index.html` in any browser — no build step or dependencies needed.
